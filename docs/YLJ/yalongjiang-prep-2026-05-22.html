这张图直接回答 4 道题

  • Agent 之间怎么编排？事件驱动（Event Manager），不是函数调用栈，不是写死的工作流，不是写死的 prompts —— Agent 之间的沟通由 Events 触发来完成，可独立运行 / 部署 / 升级 / 迭代
  • 为什么不一个大 Agent 全包？可解释 + 可审计 + 各 Agent 独立训练优化；大 Agent 出错难定位、难合规
  • 出错怎么办？每个事件可重放 · Human-in-loop 在关键节点强制介入 · 全链路审计
  • AI 准不准谁负责？每个 Agent 有独立 Evaluation Metric · Reflection Agent 持续校准 · 进入对赌合约结算
